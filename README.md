# CS-350 Emerging Systems Architectures and Technologies

## Project Reflection

Throughout this course, I worked with a Raspberry Pi to learn how hardware and software work together. One of the main projects involved building a thermostat that could read temperature, display information on an LCD screen, and use buttons and LED lights to control different settings. The goal was to understand how different components communicate and how programming can be used to control physical devices.

One thing I think I did well was sticking with the project even when things were not working. I had trouble getting my LCD screen to display words even though it was receiving power. I spent time checking my wiring, reviewing my Python code, and figuring out what the error messages meant. It took several attempts, but I eventually got the screen working. That was probably one of the most satisfying parts of the project because I could finally see the results of my work.

One area I could improve is understanding the wiring and programming before putting everything together. Sometimes I would get ahead of myself and then have to go back to figure out where something went wrong. I learned that taking my time and testing each component separately can save me a lot of frustration later.

Some of the resources I used throughout this course included online tutorials, videos, Python documentation, and troubleshooting guides. I also became more comfortable using the Linux terminal and working through error messages. These are resources and skills I can continue using in future classes or when working on other technical projects.

I think the most useful skills I gained were troubleshooting, problem-solving, and understanding how hardware communicates with software. These skills can apply to other programming projects because things will not always work correctly the first time. Learning how to identify a problem and work toward a solution is something I can use in many different situations.

To make my projects easier to understand and update, I worked on keeping my Python code organized and using clear names for different parts of the program. I also learned the importance of testing changes instead of changing too many things at once. This makes it easier to find mistakes and make improvements without having to start everything over.

Overall, this course gave me a better understanding of emerging systems architectures and how software can control hardware. I still have more to learn, but I feel more confident working with the Raspberry Pi than I did at the beginning of the course.
